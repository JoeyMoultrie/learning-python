## About this Exercise

There are multiple, small programs in this file that are used to practice different techniques to create, modify, and work with lists and tuples in Python. Techniques used are for loops to work with each item in the list; using the range function to create lists with integers; using the min(), max(), and sum() functions to work with the integer lists created with range(); list comprehensions are practiced briefly to dip my toes in ways to make code cleaner and more efficient; slices are used to work with parts of a list; and finally tuples are explored to see how to create a list of items within a program that cannot easily be changed.
